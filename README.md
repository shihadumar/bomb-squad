# bomb-squad
This is a game where the player moves around buildings sending signals to the bomb hidden in one of the buildings. The signals won't be accepted by the bomb and bounce back as the player does not posses the key. However the bounce back time from the request decreases as the player nears the bomb due to a faulty code in the bomb that will cut off signal right when it finds out the signal doesn't contain the key. Unfortunately, the number of signals one can send are limited and they must use those limited number of signals to triangulate the location of the bomb.

IMPORTANT:  Unfortunately the markers in other levels does not work due to a bug in the code, hence I have decided to restrict this prototype to just level 1.

Controls: Any key to start. Arrows or WASD to move around. Space to mark. E to end. Numbers to choose. Enter to confirm.
